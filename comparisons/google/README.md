# Google Competitor Intake Folder

Store native output files produced on Android / Pixel devices in this directory:
`comparisons/google/<id>.jpg` (where `<id>` matches the row ID from `testset/manifest.csv`, e.g., `1.jpg` or `01.jpg`).

## How to Produce Google Comparison Outputs

1. Open the original test photo from `testset/photos/` on a Google Pixel or Android phone in **Google Photos**.
2. Select **Edit** → **Tools** → **Magic Editor**.
3. Use the instruction: *"Remove all background people, keep the main subject"*.
4. Confirm the edit and save as a **copy**.
5. Export/transfer the photo at **full original resolution** (do not compress or downscale via messaging apps).
6. Save the resulting file into this folder named `<id>.jpg`.
